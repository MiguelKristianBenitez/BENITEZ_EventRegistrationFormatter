# Student Event Registration Formatter

## Project Description
This Python program collects student information and event details. It uses string methods to clean and format text and the datetime library to display the event date in a readable format.

## Features
- Accepts the student's first name and last name.
- Displays the full name in proper format and uppercase.
- Converts the section to uppercase.
- Formats the event name.
- Displays the event date in a readable format.
- Identifies the programming language and methods used.

## Programming Language
Python

## String Methods Used
- `strip()` – Removes unnecessary spaces.
- `title()` – Capitalizes the first letter of each word.
- `upper()` – Converts text to uppercase.

## Date/Time Feature
- `datetime` – Creates and formats the event date.
- `strftime()` – Displays the date in a readable format.

## Version History
- Version 1: Initial version with basic input and output.
- Version 2: Added string formatting.
- Version 3: Added date formatting.

## How to Run
1. Open the Python file in VS Code.
2. Run the program.
3. Enter the requested student and event information.
4. Enter the event month as a number from 1 to 12.
5. View the formatted registration summary.
